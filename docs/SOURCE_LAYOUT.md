# Source layout

All C# source files live under `src/`. Game and MelonLoader assemblies are kept in `references/`; project documentation is kept in `docs/`.

```text
src/
├── Core.cs
├── GregCoreIntegration.cs
├── GregHost.cs
├── MassInsert.cs
├── ModConfig.cs
├── ModuleDefinition.cs
├── ModuleRegistry.cs
├── ModuleValidation.cs
├── CompatibilityMatrix.cs
└── Patches.cs
```
